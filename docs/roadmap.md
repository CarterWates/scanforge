# Roadmap

## Phase 1

- Python package with a `scanforge` CLI
- TCP connect scanning without root privileges
- Hostname, IP, CIDR, and IPv4 range target parsing
- Port list and range parsing
- Configurable timeout and concurrency
- Optional banner grabbing
- Rich terminal output
- JSON and CSV exports
- Local test coverage for parser, scanner, engine, output, and CLI behavior

## Phase 2

- Local browser dashboard
- Scan form for targets, ports, timeout, and concurrency
- Live progress updates
- Sortable and filterable result tables
- JSON and CSV report downloads
- README screenshots and demo GIF

## Later Ideas

- Named scan profiles
- HTML reports
- Historical scan comparisons
- Common-port service enrichment
- Optional privileged discovery modes kept separate from the default scanner
